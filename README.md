# Financial Literacy Website

This is a responsive HTML/CSS/JS website for CS Vrushal Saudagar's financial literacy programs.

## Setup
Just open `index.html` in the browser.

## Folder Structure
- `/assets` – Images & videos
- `/styles` – CSS files
- `/scripts` – JavaScript files
